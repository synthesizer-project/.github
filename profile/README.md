# Synthesizer

Synthesizer is an open-source python package for generating synthetic astrophysical observables. It is modular, flexible, fast and extensible.

Read the documentation [here](https://synthesizer-project.github.io/).

## Synference

Synference is part of the Synthesizer project, and leverages Synthesizer for felxible spectral energy distribution (SED) fitting using simulation based inference (SBI) methods.

Read the Synference documentation [here](https://synthesizer-project.github.io/synference/).
